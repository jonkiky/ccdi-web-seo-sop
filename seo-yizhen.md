## SEO SOP Updates

### Robots.txt + XML Sitemap
- Ownership: Ensure that the robots.txt file and the XML sitemap are owned and managed by the SEO team.
- Validation: Regularly validate the robots.txt file and sitemap using available tools (e.g., Google Search Console).
- Monitoring: Establish monitoring protocols to check crawl status and sitemap status.
- Update Cadence: Set a schedule for regular updates to the robots.txt and sitemap files.

### Performance Numbers Capture
- Require monthly reporting of performance metrics, including:
  - PageSpeed Insights (Mobile/Desktop)
  - Largest Contentful Paint (LCP)
  - Input Delay (INP)
  - Cumulative Layout Shift (CLS)

### GA4 Guidance on Bounce Rate vs Engagement Rate
- Guidance on measuring bounce rate and engagement rate effectively to avoid misleading metrics when analyzing Single Page Applications (SPAs).
  - Implement route-change and page_view events in GA4 for accurate tracking.

### Backlinks/Referral Section
- Expand the backlinks and referral traffic section:
  - Conduct SEMrush Backlink Audit for toxic backlinks.
  - Implement referral traffic reporting.
  - Establish a disavow workflow for managing toxic backlinks.
