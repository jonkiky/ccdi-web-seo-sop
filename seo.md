Standard Operating Procedure (SOP) for Website SEO Improvements

Comprehensive Guidelines for Optimizing Website Search Engine Performance

# Purpose

This SOP outlines the procedures and best practices for implementing SEO (Search Engine Optimization) improvements to enhance the visibility, ranking, and organic traffic of a website. The goal is to ensure consistent and effective optimization across all web pages.

# Scope

This SOP applies to all team members responsible for website management and content creation. It covers on-page, off-page, and technical SEO activities.

# Roles & Responsibilities

- SEO Specialist: Oversees implementation and audits.
- Content Creators: Ensure all content follows SEO guidelines.
- Web Developers: Address technical SEO requirements.
- TPM and Fed Lead: Define target audience and review performance metrics.

# Tools Required

- Google Keyword Planner
- SEMrush
- Screaming Frog (for technical audits)
- Google Search Console
- PageSpeed Insights

# Procedure

**Step 1: Keyword Research**

**Frequency:** Monthly / per new content

- Use tools like **Google Keyword Planner** or **SEMrush** to identify relevant keywords.
- Focus on:

- Primary keyword (main topic)
- Secondary keyword (variations, long-tail)

- Analyze:

- Search volume
- Keyword difficulty
- Search intent (informational, transactional, etc.)

**Output:** Document chosen keywords for each page.

**Step 2: On-Page Optimization**

**Frequency:** For every new or updated page

- Incorporate primary keyword into:

- title tag (equal or less than 60 characters)
- meta description (equal or less than 160 characters)
- h1 heading

- Include secondary keywords naturally in:

- subheadings (h2, h3)
- body content

- Maintain:

- Readability (short paragraphs, clear structure)
- Internal linking (2-5 relevant links) - Add internal links to related content and update anchor text for relevance.
- External authoritative links

- Optimize images with descriptive alt text and compressed file sizes.

**Step 3:** **Technical SEO**

**Frequency:** Monthly

- Crawl site using **Screaming Frog**.
- Check for:

- Broken links (404 errors)
- Missing meta tags
- Duplicate content

- Ensure:

- XML sitemap is updated and submitted.
- Robots.txt is correctly configured.
- Pages are indexable.

- Perform regular website audits using tools such as **Google Search Console**.

**Step 4: Page Speed Optimization**

**Frequency:** Quarterly or after major updates

- Run **PageSpeed Insights**.
- Optimize:

- Image sizes
- JavaScript / CSS minification
- Caching

- Ensure Core Web Vitals are within acceptable range and mobile responsiveness.

**Step 5:** **Off-Page Optimization**

**Frequency:** Monthly

- Identify backlink opportunities:

- Guest posting
- Partnerships
- Direct outreach

- Track:

- Domain authority of linking sites
- Number of backlinks gained

**Step 6: Content Creation and Updates**

- Publish fresh, original, and valuable content regularly.
- Update existing pages to reflect new keywords and trends.
- Maintain consistency in style, tone, and formatting.

**Step 7: Monitoring and Reporting (Performance Tracking)**

**Frequency:** Weekly / Monthly

- Monitor:

- Organic traffic
- Keyword rankings
- Bounce rate
- Conversion rate

- Use Google Search Console for:

- Impressions
- Click-through rate (CTR)

- Maintain a monthly SEO report including:

- Traffic trends
- Keyword ranking changes
- Completed optimizations
- Issues & fixes

- Store reports in the shared drive (e.g. NIH SharePoint)

# Review and Update

This SOP should be reviewed every 6 months or annually or whenever significant changes occur in search engine algorithms or business objectives. Feedback from stakeholders should be incorporated to ensure ongoing improvement and relevance.

# GEO & AEO Consideration (Bonus)

In addition to traditional SEO, it is important to consider **Generative Engine Optimization (GEO)** and **Answer Engine Optimization (AEO)** as user behavior shifts toward AI-driven and answer-based platforms.

- Users increasingly rely on AI tools for direct answers rather than browsing search results
- Healthcare data platforms require clear, structured explanations to make complex data accessible
- Trust and authority (e.g., NIH/NCI context) should play a key role in whether content is surfaced by AI systems

## GEO (Key tactics)

**Focus:** Getting cited or used by AI tools

(AI doesn't just rank pages - it extracts answers. So, structure matters more than ever.)

**1\. Write in "answer-ready" format**

- Use clear headings like:
  - "What is X?"
  - "How to do X?"
- Provide concise summaries at the top
- Use bullet points and step-by-step formats

**2\. Add structured data (Schema markup)**

- FAQ schema
- How-to schema
- Article schema - This helps AI understand context better.

**3\. Build authority & trust**

- Show **E-E-A-T**:
  - Experience
  - Expertise
  - Author bios
  - Sources/citations
- Include real data, examples, and case studies

**4\. Create "citation-worthy" content**  
AI tools prefer:

- Definitions
- Statistics
- Original insights
- Clear frameworks

**Example:**  
Instead of vague text:

"SEO is important for websites"

Write:

"SEO improves organic visibility by helping search engines understand and rank your content based on relevance, authority, and user experience."

## AEO (Key tactics)

**Focus:** Appearing in featured snippets, voice search, and direct answers

**1\. Target questions**

- Use tools like:
  - "People Also Ask"
  - Reddit / forums
- Create pages answering specific questions

**2\. Use concise answers**

- 40-60-word summaries work best for snippets
- Then expand below

**Example structure:**

- Short answer (snippet-friendly)
- Detailed explanation
- Examples

**3\. FAQ sections**

- Add FAQ blocks to pages
- Mark them with schema

**4\. Optimize for voice search**

- Use natural language
- Include conversational phrases:
  - "How do I…"
  - "What's the best way to…"
